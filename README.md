# Personal Journal Manager

### Description

The **Personal Journal Manager** is a simple Python program that allows users to add, view, search, and delete journal entries. Each entry is automatically saved with the current date and time.

### Features

- Add a new journal entry.
- Automatically records the current date and time.
- View all saved journal entries.
- Search entries using a keyword or date.
- Delete all journal entries after confirmation.
- Handles invalid user input and file errors.
- Uses file handling and exception handling.

### Technologies Used

- `input()`
- `print()`
- `open()`
- `datetime`
- `strftime()`
- `os`
- `os.remove()`
- `try-except`
- `match-case`
- File Handling
